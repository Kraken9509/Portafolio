# Portafolio · Omar Camilo Santiago García

Portafolio digital de **Omar Camilo Santiago García**, Ingeniero de Sistemas y Especialista en Seguridad Informática.
Soporte técnico independiente **nivel 1 y nivel 2** en Villavicencio, Meta, y de forma remota en Colombia.

## Tecnologías

- HTML5 semántico con datos estructurados (Schema.org) para SEO
- CSS3 responsive (sin frameworks)
- JavaScript vanilla para animaciones e interacciones

## Estructura

```
index.html      Página principal
css/styles.css  Estilos y diseño responsive
js/main.js      Animaciones, menú y formulario a WhatsApp
favicon.svg     Ícono del sitio
robots.txt      Indicaciones para buscadores
sitemap.xml     Mapa del sitio
```

## Ejecutar localmente

Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```

## Despliegue

El sitio se publica en Vercel y se actualiza automáticamente con cada `push` a la rama `main`.
